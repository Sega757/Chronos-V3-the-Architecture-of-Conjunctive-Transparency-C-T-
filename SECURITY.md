## Scope

This security policy applies to all repositories under this organization unless specified otherwise. We consider the following out-of-scope for the bug bounty program:
- Denial of Service (DoS) attacks
- Social Engineering / Phishing
- Vulnerabilities requiring physical access to a user's device

## Reporting a Vulnerability

We practice Coordinated Vulnerability Disclosure (CVD). If you believe you have found a security vulnerability, please report it to us as described below.

Please report any security vulnerabilities responsibly.
You can send an email to security@example.com.

## Coordinated Disclosure Process

1. **Acknowledgment:** We will acknowledge receipt of your vulnerability report within 48 hours.
2. **Triage:** We will triage the report and verify the vulnerability. We may contact you for further details or clarification.
3. **Fix:** We will work to develop a fix for the vulnerability.
4. **Disclosure:** Once a fix is released and verified, we will publicly disclose the vulnerability (e.g., via GitHub Security Advisories) and credit you for the discovery, unless you wish to remain anonymous.
